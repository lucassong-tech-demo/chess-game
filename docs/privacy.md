# Privacy

Chess v0.1.0 is a local, offline desktop game.

- The application does not create accounts, display advertising, include
  analytics, or collect or transmit personal data.
- It does not contact a game server or any other network service.
- Save files are written only to the location the player chooses and remain
  on that device unless the player moves or shares them.
- Preferences are limited to the state managed locally by the desktop
  environment and application toolkit.

The application includes third-party open-source libraries listed in
[`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md). Download hosting, such
as GitHub Releases, may process ordinary service and access logs under the
host's own privacy policy; that processing is outside the Chess application.

If a future version adds networking, telemetry, accounts, crash reporting, or
cloud saves, this notice must be reviewed before that version is published.
